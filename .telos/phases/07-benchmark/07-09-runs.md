## Goal
Run the full pre-registered matrix (every corpus task × A/B/C/D × 5 repetitions plus C/D setups) once, and commit auditable evidence: sanitized event transcripts, patches and grading outputs per run, metric rows, generated tables and a run log.

## Read first
- bench/PROTOCOL.md (final preregistration; Amendments)
- bench/PILOT.md (versions, budget per cell, forecast)
- bench/README.md (runner, metrics, redaction and report usage)

## Files
- bench/results/RUNLOG.md (create)
- bench/results/runs/ (create)
- bench/results/rows/ (create)
- bench/results/runs.csv (create)
- bench/results/tables.md (create)
- bench/results/REDACTION.md (create)

## Constraints
- D-07 [proposed]: the protocol is frozen at the final preregistration commit; a defect found mid-run goes into RUNLOG and the affected cells are reported as such, never rerun selectively.
- D-11 [proposed]: one seed for the whole matrix, recorded; resume only with the same seed and the runner's resume rule; cell gaps logged.
- D-12 [proposed]: `--cap-usd 300` (or the confirmed value) and the pilot's `--cell-usd`; stop at the cap without dropping repetitions.
- Same Claude Code version and model IDs as the pilot; a forced host upgrade stops the run and is logged.
- Per run under bench/results/runs/<cell>/: sanitized transcripts (main and subagents), patch, grading output; raw files stay in the untracked out dir. REDACTION.md lists the rules and total hit counts.
- Human effort stays ≤ ~1 h: the campaign runs unattended and resumable; long wall-clock time is expected.

## Steps
- Record versions, seed and cap in RUNLOG.md; start `node bench/run.mjs --manifest bench/corpus --seed <seed> --cap-usd <cap> --cell-usd <n> --out <dir>`.
- Log every interruption, retry, timeout, refusal and skipped cell with time and cell id.
- Build rows and sanitized run evidence; write REDACTION.md.
- `node bench/report.mjs --rows bench/results/rows --manifest bench/corpus --out bench/results`.
- Check that every pre-registered cell appears in tables.md (run or with a reason) and that metrics can be recomputed from bench/results/runs/.
