## Constraints
- CLI reads git only; only the skill executes git revert after the user confirms exact hashes and dependency warnings.
- Preview --stat, newest-first task commits and transitive later dependents; never auto-revert dependent tasks.
- Task commits include STATUS/task files: preserve unrelated current Telos metadata; restore canonical task/ROADMAP/STATUS state through CLI after revert.
- Assumed: dirty tree, missing task commits/tag, merge commits or already-reverted task require stopping with a remedy; no reset/stash/push.
- When undoing a closed phase, reopen it via CLI and block affected later tasks explicitly; history changes only after successful revert.
- Read actual workflow/gate outcomes in tests; use existing task parser. Document undo skill and bundle rows.
- Snapshot current task states, ROADMAP and STATUS before revert; restore unrelated canonical state via CLI, preserve non-state task sections, then verify before committing.

## Tests (write first)
- Exact conventional task scope finds all and only target commits after phase tag, newest first, with stats and transitive dependent warnings.
- Missing tag/commits, merge commit, dirty tree and already-reverted task refuse without mutation.
- No confirmation means no git revert or state changes; failed/conflicted revert stops and leaves recovery instructions.
- Reverting a commit containing task/STATUS files preserves other tasks and current metadata; target becomes reverted through CLI only.
- Successful undo logs once, reopens closed phase, marks affected dependents blocked and preserves unrelated history.

## Interface
- ctx undo [NN-MM] is a read-only capped preview; exact commit hashes, stats, dependent task IDs and refusal reasons.
- Skill validates target from body then explicitly requests ctx undo ID; one initial fixed injection, no $ARGUMENTS in shell.
- Apply confirmed non-merge commits newest first with git revert --no-commit; reconcile saved task/ROADMAP/STATUS via CLI before an explicit-path commit.

## Edge cases
- Dirty tree or merge commit → refuse with remedy.
- Target has later transitive dependent → warn before confirmation; block after successful undo.
- Revert conflict → stop, no successful-revert HISTORY entry.
- Task commit includes planning metadata → retain unrelated state and apply target changes through CLI.
