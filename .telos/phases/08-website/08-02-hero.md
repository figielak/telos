## Constraints
- Scope is `website/` only: root `package.json`, `README.md`, `skills/`, `lib/` stay untouched.
- Content rule (D-03): state only what README, SPEC or the code says; no benchmark, token-saving or cost figures, no comparisons with other tools.
- Direction (D-02): tokens from `website/DESIGN.md`; no emoji, no pure black, no glows, no gradient text, no glassmorphism, no equal 3-column card row; concrete verbs, no filler copy.
- Below `md` every layout collapses to one column with no horizontal page scroll.
- Layout: asymmetric split, copy left and terminal right, `min-h-[100dvh]`, never `h-screen`; one `<h1>` with the exact text "From intent to completion."
- CTAs: primary links to `#getting-started`, secondary to `https://github.com/figielak/telos`. Show the real "pre-alpha" status near the headline.
- Terminal is real text in `<figure>` and `<pre>` from `src/data/terminal.mjs`, with a caption saying the session is illustrative. Its shape follows real output: `/telos:plan`, `/telos:approve`, `/telos:do`, `PASS   …`, `SCOPE  ok (N files)`, `accept NN-MM: PASS`, then a commit `<type>(NN-MM): …`.
- Long lines scroll inside the terminal (`tabindex="0"`, labelled region), never the page.
- Motion is CSS only: one staggered line reveal on `transform` and `opacity`, and a blinking cursor; `prefers-reduced-motion` shows the final state. All content is visible without JavaScript.
- Navigation: `<header>` and `<nav aria-label>` with links to `#workflow`, `#features`, `#profiles`, `#memory`, `#getting-started` and GitHub; below `md` a `<details>` disclosure, no JS framework.

## Tests (write first)

- CSS contains a `prefers-reduced-motion` rule; built HTML has no `h-screen`.
