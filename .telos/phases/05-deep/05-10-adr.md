## Tests (write first)
- Valid source creates next global NNN-title.md with date, accepted status, source and Supersedes; gaps never reuse an existing number.
- Supersede accepted ADR → old header becomes superseded by new NNN; old body bytes remain unchanged.
- Unknown/proposed source or non-accepted supersedes target → exit 1 before mutation.
- Newline title, malformed source/number or invalid options → exit 2; no path injection.
- Concurrent writer, symlink destination or interrupted publication → refuse safely with recovery guidance, no overwrite.
- Publication failure → no silent success or lost old body; recoverable evidence remains for retry.
- Exact retry → same ADR, no extra number or second supersession; conflicting duplicate → refuse.

## Interface
- adr new "<title>" --source NN:D-MM [--supersedes NNN]; deep only, success → path/number and exit 0, domain/I/O failure → 1, usage → 2.
- readAdrs(root) exposes validated headers and paths for later close/undo; no ad-hoc task/frontmatter parsing.
- createAdr(root, options) renders templates/adr.md and owns publication/locking; skill edits only body sections afterward.
